# پروژه‌های توسعه‌دهندگان برچین

۲۴ پروژهٔ مستقل برای کاربران فارسی‌زبان. [کتابخانه و دموهای آنلاین](https://barchin.net/developers)

فقط Node.js 18 یا جدیدتر لازم است. در پوشهٔ هر پروژه، `node ../../run.mjs --check` نتیجهٔ نمونه را با خروجی مرجع بررسی می‌کند. با `node ../../run.mjs --serve` دموی تعاملی را روی localhost باز کنید. دستور بدون آرگومان، نتیجهٔ JSON را چاپ می‌کند. برای تنظیم درگاه محلی، متغیر محیطی `PORT` را مشخص کنید.

`catalog.json` تعریف پروژه‌ها و کنترل‌های نمایش است. در پوشهٔ هر پروژه، `sample.v1.json` دادهٔ ورودی و منشأ آن و `expected.v1.json` خروجی مرجع را نگه می‌دارند. موتور محاسبه و نمایش در CLI و مرورگر مشترک است. مثال‌ها کلید API نمی‌خواهند. برای کار با دادهٔ زنده، مسیر احرازهویت‌شدهٔ همان اکتور یا ایجنت را از صفحهٔ پروژه باز کنید.

نمونه‌ها برداشت‌های نسخه‌دار از منابع عمومی هستند. زمان تهیهٔ بسته، تاریخ انتشار منبع و زمان مشاهده ممکن است متفاوت باشند. کد پروژه‌ها تحت مجوز MIT است. حقوق محتوای اصلی هر منبع نزد ناشر آن است.
